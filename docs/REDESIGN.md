# 界面重设计：中性灰暗房

本文记录已确认的重设计决策，作为实现的依据。可交互样稿在 `docs/mockups/`：`combined.html`（主窗口）与 `viewer-window.html`（独立查看器）。早期备选方向 `a-darkroom.html`、`b-lighttable.html`、`c-gallery.html` 保留作对照。

## 已确认的决策

- 以方向 A 为基础：中性灰深色界面，照片是主角，界面元素退后。
- 采用 B 的文件夹树与选片流程，但不用胶片条与油性笔标记的装饰。
- 统计页按 A 的设计语言重做，作为图库内的“概览”视图，图表可点击筛选照片。
- 允许删除影响原片：淘汰的照片可移到系统废纸篓（RAW 与同名 JPEG 一起），可撤销。这是对“原片只读”原则的唯一例外，且只在用户明确操作时发生。
- 保留独立查看器窗口，目标是以更高性能、更丰富的功能、更优雅的布局替代系统图片查看器。

> 视觉与组件以 [设计系统规范](superpowers/specs/2026-11-10-design-system-design.md) 和 `docs/mockups/design-system.html` 为准；下面的色值表已并入其中。

## 视觉系统

| 角色        | 值                                | 用途                                           |
| ----------- | --------------------------------- | ---------------------------------------------- |
| 窗口        | `#262626`                         | 主背景，接近 18% 中性灰，判断曝光不偏色        |
| 导航栏      | `#1d1d1d`                         | 左侧图标栏                                     |
| 侧栏        | `#212121`                         | 图库与文件夹树                                 |
| 浮起        | `#303030`                         | 按钮、输入、分段控件                           |
| 分隔        | `#3a3a3a`                         | 细线                                           |
| 舞台        | `#1b1b1b`                         | 查看器与放大镜背景                             |
| 文字        | `#ececec` / `#a6a6a6` / `#7a7a7a` | 主要 / 次要 / 提示                             |
| 星级        | `#f0c050`                         | 评级                                           |
| 留用 / 淘汰 | `#86cf9c` / `#e8786f`             | 状态色，总与图标或文字一起出现                 |
| 图表        | `#5b8fd9`                         | 单系列图表，已按深色表面校验亮度、彩度与对比度 |

- 扁平：不用阴影、渐变、模糊。层次靠表面明度差与留白。
- 字重只用 400 与 500；最小字号 11px。
- 动效时长 120 / 180 / 240–280ms，缓动 `cubic-bezier(.2, 0, 0, 1)`；只用于回应操作（打开、切换、确认）；`prefers-reduced-motion` 下全部即时。
- 淘汰的照片保持原亮度，用顶部红色细条与淘汰图标区分；“隐藏淘汰”可一键隐藏。

## 主窗口

```
┌──┬──────────────┬──────────────────────────────────────────────┐
│  │ 图片库    +  │ 标题 路径         照片 选片 概览     搜索 ⌘K │
│图│ ▾ 2026 旅行  │ 64 张 [相机：X-T5 ×]        隐藏淘汰  大小   │
│标│   ▾ Kyoto    │ 10月18日 周日  京都，岚山，11 张          ┃  │
│栏│     01 岚山  │ ▇▇▇▇ ▇▇▇▇▇▇ ▇▇ ▇▇▇▇▇ ▇▇▇▇         ┃  │
│  │   Nara       │ ▇▇▇▇▇▇ ▇▇▇ ▇▇▇▇▇▇▇ ▇▇▇▇    ┃  │
│  │ 城市漫步     │          │
└──┴──────────────┴──────────────────────────────────────────────┘
```

- 左侧图标栏：图片库、位置、导入、设置。
- 图库侧栏（⌘B 收起）：图库与各级子文件夹，显示数量与在线状态。点击任一级把三个视图都限定在该文件夹。每级“⋯”菜单：只扫描此文件夹、从这里开始选片、导出这里的留用、查看概览、在访达中显示。
- 顶栏：标题与路径、视图切换（照片 / 选片 / 概览，⌘1/2/3）、搜索（⌘K 命令面板）。
- 筛选以可移除的标签显示在视图上方；来自概览图表的点击也生成标签。

### 照片

- 按拍摄日期分组，日期标题吸顶；照片按原始宽高比排成齐行（justified rows）。
- 右侧时间轴拖动条，悬停显示所在日期。
- 单击选中，双击或 Enter 在主窗口内打开查看器：照片从缩略图原位放大（240–280ms），Esc 缩回原位。
- 悬停时在照片底部显示文件名与星级；旗标以角标显示。

### 选片

- 左侧放大镜，右侧文件名、直方图（已看过的照片从缓存读取）、曝光参数、星级与 P / X 按钮，底部胶片条。
- P 留用、X 淘汰后自动下一张（可关闭）；胶片条底部绿线或红线表示旗标，看过的照片变亮。
- 顶部显示进度（已看 / 总数）与留用、淘汰计数。
- “完成选片”：左栏留用（导出 JPEG、复制原片），右栏淘汰（移到废纸篓，显示文件数与占用）。

### 概览

- 不用卡片格子，以分区与细线组织。
- 顶部四个数字：照片数、留用率、原片占用、未处理数。
- 拍摄时间线：按天连续排列，空白日子留空，出行呈簇状。
- 选片进度：留用 / 淘汰 / 评了星 / 未处理的分段横条，带文字图例。
- 相机、镜头为排行列表；焦距、ISO 为小柱状图。
- 每个柱子、分段、行都可点击：切到“照片”并加上对应筛选标签。

## 查看器：同一组件，两种外壳

|          | 主窗口内                   | 独立窗口                                                |
| -------- | -------------------------- | ------------------------------------------------------- |
| 入口     | 图库内双击 / Enter         | 访达打开、文件关联、拖入、“在新窗口打开”                |
| 浏览范围 | 当前视图筛选后的照片       | 所打开文件所在文件夹，按需列出，不加入图片库            |
| 外观     | 从缩略图放大进入，带胶片条 | 照片铺满窗口，标题栏与底栏浮在照片上，约 2 秒无操作淡出 |

共用：解码与渐进加载（先显示已缓存的小档，再换 `p2560`）、预取前后各一张、滚轮以光标为中心缩放、双击或 Z 在“适应窗口”与 100% 间切换、拖动平移、1–5 评星、P / X / U 旗标、⌘⌫ 移到废纸篓（可撤销）、I 信息面板（直方图、曝光、文件）。

独立窗口额外提供：不在图库内的文件夹提示“评级和旗标只保存在本机”与“加入图片库”；“更多”菜单：在图片库中显示、加入图片库、导出、拷贝、在访达中显示、幻灯片、对比。

## 删除

- 只在用户明确操作时执行：查看器 ⌘⌫、照片菜单“移到废纸篓”、完成选片的淘汰栏。
- 使用系统废纸篓，RAW 与同名 JPEG 一起移动；操作后可撤销（从废纸篓放回原处）。
- 图库记录标为已删除并保留 30 天，期间可恢复评级、旗标与裁剪；之后清理。
- 远端（NAS）照片不提供移到废纸篓；在界面中说明原因。

## 缓存

- 直方图由已缓存的预览档计算并保存在内存缓存中，同一照片再次查看不重新解码原片。
- 独立查看器列出文件夹只读文件名与大小，不读图片内容。

## 实现顺序

1. 后端：文件夹树与按文件夹筛选、概览统计、移到废纸篓与恢复、直方图缓存、文件夹同级文件列表。
2. 设计 token 与主窗口外壳（图标栏、图库侧栏、顶栏视图切换）。
3. 照片视图（按日分组的齐行布局、时间轴、筛选标签）。
4. 主窗口内查看器与放大转场。
5. 选片视图与完成选片。
6. 概览。
7. 独立查看器窗口。
