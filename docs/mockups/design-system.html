原则

暗房：中性灰让照片成为界面里唯一有颜色的东西。整个应用只用这一套颜色、字号、尺寸和组件；页面之间的差别只来自内容，不来自各自的样式。

照片优先

界面不加颜色；状态色只用于留用、淘汰、警告与错误，并总与图标或文字同时出现。

扁平

不用阴影、渐变、模糊。层次靠表面明度：舞台 < 侧栏 < 窗口 < 浮起。

一处一个主操作

每个页面或面板最多一个主按钮；同一件事只有一个入口，其余放进“更多”。

颜色

表面从暗到亮四级，文字三级。状态色在深色表面上校验过对比度，浅色主题各有一套。查看器舞台在两种主题下都是深色。

主按钮用文字色反白（深色主题为浅底深字），不另设品牌色。状态底色用同色 14% 透明度：--tint-pick --tint-reject --tint-warn --tint-info。

文字

七级字号，只有 400 和 500 两种字重。界面正文 13px；14px 用于说明性段落；数字统一等宽。

动效

只回应操作，不做装饰。缓动统一 cubic-bezier(.2, 0, 0, 1)；减少动态效果时全部即时。

页面结构

所有页面同一个骨架：56px 页头（标题、视图切换或步骤、至多一个主操作和“更多”），下面是 44px 工具栏（可选），再下面是内容。内容只有两种版式：单栏（最宽 760px，设置、对话类）和主栏 + 300px 侧栏（导入、详情类）。
