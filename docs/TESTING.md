## 运行检查

需要 Rust 1.90+、Node.js 22+、pnpm 9 和相应 Tauri 系统依赖。

```powershell
pnpm install --frozen-lockfile
cargo fmt --all -- --check
cargo test --workspace --locked
cargo clippy --workspace --all-targets --locked -- -D warnings
pnpm test
pnpm typecheck
pnpm build
$env:NEBULUME_BROWSER_CHANNEL = 'msedge'
pnpm --filter @nebulume/ui test:browser
```

未设置浏览器变量时使用 Playwright Chromium；需先安装对应浏览器。Cargo 依赖已缓存时可增加 `--offline`。

Rust/UI bridge 检查先运行 `cargo build -p neb-cli`，再运行 `node scripts/smoke.mjs --ui`；脚本自行启动独立端口前端服务，可用 `NEB_BROWSER_CHANNEL=msedge` 选择已安装浏览器。

原生桌面验收使用 release 程序和独立 `NEBULUME_DATA_DIR`。使用 `--data-dir` 隔离 CLI 数据。不要让自动化读取日常图库、真实凭据或无关目标路径。

系统凭据库契约默认用可注入 mock 测试。真实凭据库测试需单独显式运行，只创建随机测试记录并在结束时清理，不读取用户凭据。

## 必须覆盖的行为

### 索引与影像

- 大于分段预算的RAW搭配小型内嵌JPEG、稀疏远偏移IFD及两种字节序：预览、方向、直方图和常用EXIF正确，读取量有界，不请求完整原图。
- 真实预览预算耗尽只提供显式下载恢复；版本/协议/传输错误不自动回退。chunked响应恰好用满预算可成功，超长响应最多探测一个字节后拒绝。
- schema 迁移、并发初始化、重开、单文件隐藏索引和扫描幂等；保留资产身份、评级、裁剪与来源绑定。
- 整库组合查询、排序后分页、RAW/JPEG 配对与歧义隔离；拍摄时间未知值在升降序下均置后。
- EXIF 方向、损坏文件、裁剪边界和直方图；导出不覆盖，原文件哈希不变，内嵌预览不能冒充 RAW 原始导出。
- 拍摄时间只取 DateTimeOriginal；非法/缺失/冲突日期、可选子秒/时区损坏、解析预算、版本校验及重试。已有确认元数据不能被同版本的不完整预览覆盖。

### 存储、缓存与并发

- 本地根作用域、路径穿越及符号链接；WebDAV 属性拆分、失败属性、无效长度和分页；S3 签名、分页与会话凭据。
- 局域网 HTTP 与公网边界；TLS 默认拒绝不受信证书，确认指纹后连接，指纹变化/过期拒绝，连接信任互相隔离。
- 冷索引不 GET 正文、按需获取、离线重开、强版本 Range、精确响应长度、读取预算及失败时保留旧原图。
- 缓存总额预约、固定/租约保护、过期回收、预览保留、非法目录拒绝、迁移取消/提交/崩溃恢复和磁盘离线。
- 远端读取或扫描停顿时，本地列表、预览和查询继续响应；网络和文件哈希不占全局目录锁。重绑后拒绝旧扫描页发布。
- 拍摄时间任务取消不开始下一读取，保留完成项；失败保持可重试。单响应前缀回退不增加完整原图缓存。

### 导入

- 源目标嵌套、源文件变化、同名异内容、同内容去重、目标读回校验、重复执行和重启恢复。
- RAW/JPEG/XMP 伴随组日期继承、冲突、成员不可读及执行失败；失败停止后续成员，不留下可执行残组。
- 导入不删除来源、不覆盖无关目标；逐项结果能解释成功、跳过与失败。

### 界面与窗口

- 四区导航、建库、连接编辑、计划审核、导入结果、独立查看、信息栏、裁剪/导出、错误恢复和窄窗口。
- 迟到响应不串库或串图；原图刷新使对应预览失效，评级或元数据更新不重建无关缩略图。
- 离屏待处理项取消、当前图优先、本地与远端队列隔离；窗口获焦保留列表、详情、选择和滚动位置。
- 对焦信息自动检测；无有效记录时按钮禁用、提供悬停及可访问说明，不伪造中心点。叠加层随方向、缩放和平移，裁剪编辑期间隐藏。
- 拍摄索引开始、进度、停止、失败重试和跨页继续；终态协调列表一次，保留已加载图像节点。
- 深浅/系统主题持久化与窗口同步，键盘操作和可访问名称。
