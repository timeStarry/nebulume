# Lumen 品牌识别与设计矩阵

本文档定义 **Lumen** 的品牌识别规范（命名、语言语气、三态徽标、色彩边界与工程兼容约定），与 `packages/ui/src/tokens.css` 的中性暗房设计系统配套使用。

## 1. 名称与窗口标题规范

- **产品名称**：`Lumen`（纯英文呈现，界面与系统级入口均不附加中文副名）。
- **产品定位语**：
  - 中文：`安静、顺手的照片库与选片工具`（完整说明：`安静、顺手的照片库与选片工具 · 原片始终只读`）
  - 英文：`Quiet, effortless photo library and culling tool`
- **窗口与标签标题**：
  - 主窗口：`Lumen`
  - 独立看图窗口：`<文件名> — Lumen`

## 2. 语气与文案准则（Verbal Identity）

- **平实陈述，拒绝修辞腔**：文案直接说明功能行为与数据边界（如「照片留在原处」「原片始终只读」），不使用夸张口号或工程内部黑话（如「资产基座」「运行时状态」）。
- **诚实说明限制**：对平台能力、只读网络目录或证书异常给出单行清晰原因与下一步可执行动作。

## 3. 三态六叶光圈徽标体系（Mark System）

Lumen 沿用精密六叶光圈几何造型，采用 **「暗房钛银 + 暖金漫射」** 配色体系，消除冷蓝底色与界面暗房灰之间的色温割裂：

1. **桌面圆角图标（`crates/neb-app/icons/*`、`packages/ui/public/favicon.svg`）**
   - 底板：阳极氧化中性炭黑阶梯（`#242426 → #141416`），配微弱顶部高光内倒角，与 `--nl-stage`（`#1b1b1b`）无缝衔接。
   - 叶片：五片拉丝钛银阶梯（`#F5F5F1 → #7D7E83`）+ 右下单叶暖琥珀光学折射（`#F7DA9C → #BA8A43`，呼应 `--nl-star: #f0c050`）与柔和漫射高光。
2. **深色界面内嵌徽标（`packages/ui/src/assets/brand-mark.svg`）**
   - 透明底六叶钛银 + 暖金光圈，用于深色主题下的左侧主导航栏（`24px`）与「设置 → 关于」品牌名片（`36px`）。
3. **浅色界面单色徽标（`packages/ui/src/assets/brand-mark-ink.svg`）**
   - 主体采用中性暗房墨黑 `#1F1F1F`（对齐浅色主题 `--nl-text`），右下单叶采用浅色主题暖琥珀 `#8A6216`（对齐浅色 `--nl-warn`），消除浅色界面下的冷蓝色偏。

修改任何图标资产后，必须运行 `python3 scripts/make-icon.py` 校验全部 SVG、PNG、ICO 与 ICNS 尺寸与校验和结构。

## 4. 品牌色与看片区边界法则

- **暖琥珀金（`#F0C050` / `#E3B25C`）仅作为光学点缀色**，限定用于品牌徽标折射高光与照片星级标记。
- **审片环境零干扰**：常规主按钮、选中环、工具栏与画布背景严守中性黑白灰（`--nl-primary`、`--nl-stage`、`--nl-canvas`），不得将品牌点缀色用作大面积背景或主操作按钮底色，以免产生同时对比色偏影响审片判断。

## 5. 系统标识与数据连续性约定

- 展示层全面使用 `productName: "Lumen"`（macOS 打包为 `Lumen.app`）。
- 底层应用标识保持 `identifier: "app.nebulume.desktop"`、系统凭据库服务名保持 `app.nebulume.storage.v1`、前端偏好键前缀保持 `nebulume.*`，确保升级前后本地图库数据库、预览缓存、网络存储凭据与用户偏好 100% 原地兼容。
