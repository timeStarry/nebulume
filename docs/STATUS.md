# 实施状态

版本：0.2.2。更新日期：2026-11-13。

目录升级到 schema14（在 schema13 性能基座基础上新增 Stage 4 完整虚拟组织层：`color_label` 色标体系、`collections`/`collection_items` 手动与智能精选集、`keywords`/`asset_keywords` 层级关键词树）；未知结构拒绝迁移，旧程序回退需要恢复备份。具体检查结果见 TESTING.md。

当前发布 Windows x64 安装器和独立程序。Rust 核心、CLI 与 Tauri 桌面界面共用命令服务；其他平台尚未完成本版本构建与实机验收。

## 已实现

- 本地目录直接建库，WebDAV/S3 连接可提供多个来源目录图库；库名称、来源和 RAW/JPEG 合并偏好可编辑。移除登记保留原文件，存储源被引用时禁止删除。
- 搜索、格式、最低评级和排序组合查询，整库筛选后分页；无歧义的同目录同名 RAW/JPEG 可合并显示；合并显示时评级与旗标同时作用于两个文件，裁剪配方各自保留。
- 默认按 EXIF DateTimeOriginal 拍摄时间排序，保留子秒及已有时区。文件创建和修改时间单独存储；无有效拍摄记录时不回退为文件时间。旧图库可后台补索引，支持协作式停止和重试。
- WebDAV/S3 递归目录索引、按需读取、持久预览和原图缓存。部分经典 TIFF/RAW 支持有界分段内嵌 JPEG 读取；可固定原图快照离线查看。
- 用户可设置缓存位置、1–1024 GiB 总上限、普通原图保留期限和自动/手动获取策略，支持分类清理、迁移及中断恢复。
- 局域网（含 RFC 6598 CGNAT / Tailscale 网段）HTTP、标准 HTTPS 和按源确认的设备证书（过期轮换后支持重新核对指纹更新）；凭据默认保存在系统凭据库，支持会话凭据，不写入配置、SQLite 或日志。
- 位置可用性：在线 / 未检查 / 离线 / 需要登录 / 证书待确认 / 错误，来自实际操作结果；不可用的库置灰但仍可浏览与打标，扫描禁用并说明原因。
- 本地库扫描识别移动和改名（v9 `quick_hash`），评级、旗标、裁剪与导入批次随照片保留；多个相同副本不自动合并。
- 位置表（v7）与隐式文件夹位置；存储卡身份、绑定、导入方案与导入批次（v8）；结构化目录整理规则。
- 导入到 WebDAV / S3 图片库：显式写入测试、不覆盖发布与 SHA-256 校验、按目录记录判重（含“疑似重复”）。仅经回环模拟服务器验证，尚未对真实 NAS 产品做兼容性验收；S3 暂不支持超过 5 GiB 的分片上传。
- 内容指纹：图片库设置中显式建立，网络图片库会先提示需要完整下载的数量与大小再开始。
- 外接库盘离线浏览与手动无损重定位（`library.relocate`）：外接移动硬盘未挂载时仍可离线浏览缩略图、打标与整理精选集，挂载路径变更后支持一键重绑目录并保留全部资产 ID、配方、精选集与关键词；尚不支持跨卷序列号全自动后台重绑；应用偏好仍在 localStorage。
- 虚拟组织层与效率工具（Schema v14）：红/黄/绿/蓝四色色标（`6–9` 快捷键、网格圆点、筛选、`BatchDock`、`⌘Z` 撤销）、手动精选集与动态规则智能精选集（`collections`）、`>` 分级层级关键词树与前缀筛选（`keywords`）、相邻 ≤ 2 秒同机身连拍自动折叠栈（`burst-stacks.ts`）、`⌘K` 全局命令面板与网格右侧时间轴快速定位滑尺（`DateScrubber`）。
- 本地扫描自动识别并跳过 macOS / 摄影软件封装包目录（`.photoslibrary`、`.aplibrary`、`.lrdata`、`.app` 等），防止系统图库衍生缩略图污染目录树。
- 设计系统（[规范](superpowers/specs/2026-11-10-design-system-design.md)，开发版 `?design=1` 为组件参考）：统一的 token、内置 Tabler 线性图标与共享组件，所有页面同一骨架（设置页收敛为 4 个单栏标签页，关于页去除裸 JSON，概览页升级为自适应日/周/月时间线与双栏卡片仪表盘）；`pnpm test` 包含设计检查，拦截组件与 token 之外的颜色、阴影、字重与像素字号。查看器在两种主题下都是深色。
- 查看器四角叠加信息可自定义（拖放或键盘），信息栏字段可固定与排序。
- 导入为一个步骤条、一个主操作的三步流程，历史在侧边抽屉；核对阶段支持按单张或按拍摄日勾选子集，支持双盘同步校验备份（`backup_destination`）、伴随组同号重命名（`keep` / `date_prefix_seq` / `prefix_original`）、实时字节/张数进度与协作式安全取消（`import.status` / `import.cancel`），以及导完安全推出存储卡（`eject_volume`）。
- 本地 `.xmp` 伴随生态互通（`xmp.rs`）：初次扫描自动识别同名 `.xmp` 的星级、留用/淘汰旗标与轴对齐裁剪，支持开启自动同步（`xmp.policy.set`）或单张/批量/整库手动读写（`asset.xmp.write` / `asset.xmp.read`），合并时无损保留 Lightroom / Camera Raw 既有 `crs:*` 冲印参数与 `dc:*` 主题词，外部精修软件交接（`open_external`）前自动落盘 `.xmp`，原片始终只读。
- 预设化交付导出面板（`ExportDialog` + `export_with_options`）：支持长边像素上限（`256..=16384`）、JPEG 品质（`30..=100`）、色彩空间（保留原色彩配置 / `sRGB` / `Display P3` / `Adobe RGB (1998)` 线性光矩阵色域转换与标准 ICC v2.1 嵌入）、四类命名规则及自定义预设保存，同时保留一键快速导出入口。
- 深色暗房界面（见 [REDESIGN](REDESIGN.md)）：图标栏、图库与子文件夹树侧栏（直接展示库内子目录，不重复挂载图片库本级根目录）、照片 / 选片 / 概览视图；照片按拍摄日分组的齐行布局，日期吸顶；主窗口内查看器带放大转场。
- 概览：所选范围的数量、留用率、占用与时间线、选片进度、相机镜头与焦距 ISO 分布，图表点击即筛选（`asset.stats`）。
- 移到系统废纸篓（v11 `trashed_at`）：网格、查看器与“完成选片”，RAW 与同名 JPEG 一起，可撤销；记录保留 30 天。macOS 记录废纸篓位置以便放回，网络存储不支持。
- 独立查看器浏览所打开文件的文件夹（`file.siblings`，逐张 `file.open`），不在图片库时可一键加入。
- 选图模式：从图库当前筛选结果（`Shift+C` 或“选片”）在主窗口进入，快捷键打星与留用/淘汰旗标，250ms 确认动效后可自动下一张（可在工具栏和设置中切换），支持单张与 2 张 / 4 张同步缩放平移对比查焦台（`CompareStage`）、高光/暗部溢出斑马纹警告（`J`）、会话内撤销；网格可按旗标筛选。旗标只写目录。
- 独立查看器、文件路径启动、原图 1:1 查焦（`Z` 后台无缝升级 `full` 9600px 高清档）、RAW 相机内嵌预览秒开与 `R` 传感器显影手动切换、全屏、EXIF、直方图、评级、支持常见摄影画幅比例（自由/原图/3:2/4:3/16:9/4:5/1:1 及横竖互换）的非破坏裁剪和保留广色域 ICC 的 JPEG 导出。安装器按平台诚实登记受支持格式关联候选（全平台含 `.cr3`，macOS 另含 `.heic`/`.heif`/`.avif`），由用户选择默认应用。
- 查看器采用 `40px` 常驻非遮挡窄顶栏（设置中可开启自动隐藏）与基线等高对齐的 `[›] 文件名` 侧栏头；切图采用常驻双缓冲舞台、精确宽高比锁定盒与双向邻帧 `p2560` 预解码缓存（12 帧 LRU），连续翻看零尺寸跳变、零模糊闪烁。检查器打开即显示列表中的已知信息，完整详情到达前不整块替换。检查器滑入 180ms，主窗口内查看器从缩略图原位放大 280ms，减少动态效果时为即时切换。独立查看窗口无网格转场。
- 桌面版扫描本地图片库后，单个后台线程按当前网格档位为未缓存的本地照片渲染缩略图（设置中可关闭）；远端照片不参与，不触发下载。新的扫描或更新安装会在照片之间取消正在进行的预生成。
- 桌面版监视在线的本地图片库文件夹（macOS FSEvents、Linux inotify、Windows ReadDirectoryChanges），影像文件或文件夹新增、删除、移动、改名后静默 3 秒，自动执行与手动相同的增量扫描，并就地刷新已打开的网格；隐藏路径与非影像文件不触发。设置中可关闭。网络存储不监视。
- 部分 Nikon AFInfo2 对焦区域解析与覆盖层；无有效记录时禁用按钮并说明原因，标记随方向、裁剪、缩放和平移更新。
- 深色、浅色及跟随系统主题，窄窗口导航，窗口间变更同步及网格状态保留。
- 挂载卷枚举和手选来源目录；导入计划审核、内容去重、伴随组检查、校验复制、逐项结果和完成后自动索引。

## 已知边界

### 图像

- RAW 使用 rawloader 基础传感器渲染，支持范围受机型限制。默认预览优先提取相机内嵌全尺寸 JPEG 以获得秒开体验与相机直出色彩，支持 `R` 手动切换传感器显影；解码失败时回退内嵌 JPEG 仅用于查看和直方图，不能替代 RAW 全尺寸导出。
- Canon `.cr3` 在全平台通过纯 Rust 有界 ISO-BMFF 解析器支持元数据、拍摄时间与本地/远端内嵌 JPEG 预览（暂不支持传感器显影与 RAW 全尺寸导出）。`HEIC/HEIF/AVIF` 在 macOS 通过原生 `ImageIO` + `CoreGraphics` 支持索引、保留广色域 ICC（如 Display P3）的分档预览与 JPEG 导出；Windows/Linux 暂未内置 HEIC/AVIF 解码器。
- 查看器默认请求 `p2560`（最长边 2560px），查焦放大超过 `p2560` 时按需升级 `full`（最长边 9600px）。预览与 JPEG 导出保留源文件与内嵌预览的 ICC 色彩配置，并对 EXIF 标记为 Adobe RGB（`ColorSpace=2` / `InteropIndex=R03`）但未带 ICC 的图像自动合成标准 `Adobe RGB (1998)` ICC v2.1 配置；RAW 传感器显影按 sRGB 输出，不做软打样或自定义 DCP 矩阵。导出不保留源 EXIF，原文件永不修改。
- 对焦区域限于标准 JPEG EXIF/TIFF 中部分 Nikon Type3 MakerNote 2.10/2.11、AFInfo2 0300/0301 的明确坐标，不推断点位编号；选定区域不保证合焦成功。
- 拍摄时间补索引只读取 JPEG APP1 EXIF 或经典 TIFF 主图 EXIF，不保证所有 RAW。无时区记录按相机当地日期时间排序，不推断时区或统一换算为 UTC。

### 远端与缓存

- 远端只读，尚无上传、双向同步、服务器衍生图接口或周期性自动扫描。
- 扫描最多 50,000 项、2,048 个目录、4,096 页；不完整列举不将文件标记为丢失。同路径同大小的内容替换需显式重新读取原图。
- 普通 JPEG/PNG 首次预览通常需要完整下载。Range 读取依赖可靠版本标识和服务器支持，无法使用时按获取策略处理。
- 离屏尚未派发的请求可撤销，已开始的网络读取不会即时中断。Tauri 2 的自定义协议在 WebView 放弃请求时不通知后端，因此已开始的本地解码同样会做完；并发上限（缩略图 4、查看器 2）与同一照片的锁加内存缓存保证重复请求不会重复解码。
- RAW 解码仍使用 rawloader。设计要求在真实相机样本集上对比覆盖率后才切换到 rawler（支持 CR3），仓库中没有 RAW 样本，此项未做。
- Catalog 仍为单写连接，未引入只读连接池：扫描在文件之间释放锁，元数据读取、首尾哈希与 EXIF 解析都在锁外进行；`asset.list` 翻页复用有序 ID 列表后，读操作只持锁执行单条短查询。迁移仍用手写版本链（IMMEDIATE 事务内检查版本、拒绝更新版本创建的库），未换成 `rusqlite_migration`，两者行为相同，替换没有用户可见收益。拍摄时间索引停止后保留已完成结果。
- 固定离线内容是快照，远端更新后需显式刷新。缓存位置必须满足安全发布要求，FAT/exFAT 不可用作缓存目标。
- 局域网 HTTP 和设备信任不适用于公网；证书变化须重新确认，过期证书须更新。带 scope 的 IPv6 链路本地 URL 尚不支持。

### 导入与平台

- 来源是挂载目录，可读取 FAT/exFAT；本地目标必须支持安全硬链接发布，例如 NTFS、APFS、ext4，同时支持通过写入测试的 WebDAV/S3 远端目标与本地副盘双盘备份。
- 已支持导入实时进度查询、伴随组边界协作取消、可移动卷安全推出与本地副盘同步备份；尚无断点续传、热插拔自动监听事件或公有云直传。
- RAW/JPEG/XMP 伴随组支持预检和成员失败停止，已成功成员保留；没有组级事务或回滚。
- Windows 系统凭据库有实际验证；macOS Keychain、Linux Secret Service 尚无本版本实机验收。
- Windows 包未签名。安装/卸载、系统默认文件关联，以及 macOS/Linux 发布包仍需单独验收。
- 大规模目录、峰值内存和长期运行仍需专项性能验证。
